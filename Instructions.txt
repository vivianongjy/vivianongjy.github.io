SELECT AND MOVE TEXT
Open Owner edit and enter your GitHub access key.
Click existing text to select it. Type directly as before. Drag its selection border's Move grip to reposition the whole text box without selecting its letters.
Circles, pictures, cards and boxes still support direct dragging. Phones use the Move grip or a box's dotted top edge.

ALIGNMENT AND ROTATION
A selected item shows Left / Center / Right and Top / Middle / Bottom controls, relative to its containing section or main page.
Pink guides appear near matching edges and centers during dragging. Items snap when close to a guide. Guides: on/off switches snapping; holding Alt during dragging temporarily bypasses it.
Drag the circular rotation handle or enter an angle in degrees. Rotation snaps near 15-degree increments; holding Shift forces those increments. Straighten resets the angle to zero.
Style opens text size, color, spacing and other appearance controls for the selected item.

INSERT OBJECTS
Text box inserts editable text.
Picture uploads a resized photo; add a description and choose its width.
Emoji inserts any emoji or text symbol you type or paste.
New objects are placed inside the selected page section (or the first section if none is selected). Their Edit and Delete controls appear in the selection toolbar. Drag them to arrange them alongside existing content.
The width of an inserted object can be changed in its Edit dialog. Pictures display uncropped at their natural proportions.

APPLY AND PUBLISH
Apply object previews it on your page.
Save changes publishes the content, arrangement and inserted objects through GitHub.
Guides, selection borders and editing toolbars never appear to visitors.
Exit / discard leaves editing and clears the key on reload.
Desktop and mobile moves remain independent; arrange the phone layout separately where needed. New objects have a default phone placement and width.

LAYOUT NOTES
This is a website canvas with PowerPoint-style controls, not Microsoft PowerPoint or a .pptx editor. Objects remain within their page/section. Free placement can overlap other content; use guides, Undo move or reset position to arrange them. Inserted objects expand their section when needed.
Text is plain text, including Unicode emojis. It does not accept arbitrary HTML or scripts.
