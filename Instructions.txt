PUBLIC SHOP DISPLAY / SAVE & EXIT

Upload shop.js and inline-editor.js to the root of your GitHub repository:
https://github.com/vivianongjy/vivianongjy.github.io/upload/main
Commit and wait for GitHub Pages to publish. Refresh business.html.

Do not upload or replace business-content.json. Your existing products are preserved.

After adding or editing products, set availability to Available, Apply product,
then Save & exit. This saves pending changes before leaving. If GitHub rejects
saving, Edit mode stays open with the draft and error message.

Public visitors get a fresh catalogue request when opening the page, returning
to it or pressing Refresh shop. GitHub Pages still needs time to publish commits.
Available and sold-out products appear publicly; Hidden products stay owner-only.
Order inquiries can stay closed while the public catalogue is visible.
