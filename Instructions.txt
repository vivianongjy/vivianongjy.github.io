OWNER EDIT: CONTENT AND LAYOUT

ONE-TIME UPDATE
Upload cms-content.js, inline-editor.js and inline-editor.css from this folder to the root of:
https://github.com/vivianongjy/vivianongjy.github.io/upload/main
Commit and wait for GitHub Pages to finish publishing, then refresh your website.
You do not need to replace any content JSON or uploaded photos.

ONE ENTRY
The footer now has only Owner edit. It replaces Owner sign-in and Edit this page.
Enter your private GitHub repository access key there to edit the current page. Editing controls stay hidden from visitors.

DIRECT CONTENT EDITING
Click outlined text to edit it. This now includes previously fixed headings, captions, navigation labels, family counters and other page text.
Use existing photo controls for portraits, life stages, memories, app logos and background uploads.
Click a contact circle to edit its app logo/link. Move circle left/up or right/down changes its order.
Background & song updates the background image, panel opacity and song.

LAYOUT
- Set circle columns separately for desktop and mobile.
- Adjust circle diameter, gap, left/center/right alignment and fill/whole-photo fit.
- Reorder the four homepage portraits.
- Position the background horizontally/vertically, choose fill or full-image fit, and adjust its light overlay.
- Change page width, base text size, overall text alignment, accent and panel colors, and chapter-card spacing.
- Show/hide decorative scenery.
- Move page sections up/down.

EDIT ANY ITEM
Select a page item to edit its text or destination link where applicable. Adjust its text size, color, alignment, line spacing, outside/inside spacing, rounding, maximum width, or visibility. Reset this item's styling restores its theme styling.
Hidden items remain available in the selector so you can show them again.
Use this for headings, navigation, captions, panels, sections and other parts without their own dedicated editor.
App circles, photo galleries and memories keep their dedicated editing controls.

APPLY AND SAVE
Apply previews changes on the page; it does not publish them.
Save changes publishes your edited content and appearance through GitHub.
After GitHub Pages finishes publishing, visitors see the saved changes.
Exit / discard leaves Edit mode and removes any unsaved edits after confirmation.
Your access key stays in tab memory and is cleared on reload/exit. Re-enter it on another page.

SCOPE
These controls edit website content and supported layout/style properties. They do not edit the source code, behavior inside Spotify/YouTube players, or the individual strokes in an illustration. Backgrounds and logos can be replaced with your own images.

TESTING
Simulated GitHub tests verified content saves, circle size/alignment/columns, mobile layout, background positioning, section order, individual text/styles, visitor rendering after saving, owner-only controls, photo upload, contact editing, personal stages, conflict protection and exiting. No real repository content was changed during testing.
