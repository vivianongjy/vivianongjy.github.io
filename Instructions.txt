Commit, wait for GitHub Pages to finish publishing, and refresh your website.
Existing content JSON, layouts, photos, songs and contacts are preserved.

USE
1. Select Owner edit and enter your usual website access key.
2. Click a portrait circle, contact circle, photo, memory card or box to open its editor. Click outlined text to type directly.
3. Drag a circle to move it within its visual/contact section. Drag boxes across the main page area. On a phone, drag circles directly and drag boxes by the dotted top edge; scroll from the rest of the page.
4. Use Undo move to reverse the last movement. Click a moved item and choose Reset position to return it to its normal place.
5. Save changes publishes the arrangement and content changes. Nothing is published just by dragging.
6. Exit / discard leaves the owner editor and clears the key when the page reloads.

Desktop and phone positions are stored separately. Arrange the phone view separately if you want a custom phone layout. Keyboard users can focus an item and use Alt + arrow keys to move it (Shift for finer steps); Escape resets its position.

The repeated per-item edit buttons and Layout shortcut are hidden/removed from the page editing flow. Advanced item styling remains in the box editor; circle appearance settings are available from a portrait circle's editor. Background & song and Add memory remain in the owner toolbar.

MOVEMENT
Moving items changes their visual positions; the page still keeps their original space in its normal flow. Items can overlap if you place them on top of each other. Reset or Undo restores their position. Movement is bounded to the main page or the circle's section to avoid moving items off the page.

Visitor pages show only the saved arrangement, with no drag edges or editing controls. GitHub authorization is still required for saving. Your key is kept only in tab memory.

Verification used a simulated GitHub API, including mouse/touch movement, direct clicking, undo, explicit saving, independent phone positions, and visitor rendering. No real repository content was changed during testing.
