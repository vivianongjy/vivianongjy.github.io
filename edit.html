First-time setup
  1. Create a fine-grained GitHub access key ↗
  2. Choose resource owner vivianongjy, an expiration date, and Only select repositories → vivianongjy.github.io.
  3. Under Repository permissions, set Contents → Read and write. Generate the key.
  4. Paste it into this sign-in box. Keep the key private; do not send it in chat or upload it to GitHub.
